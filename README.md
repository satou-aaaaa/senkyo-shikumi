# 選挙のしくみ

投票のしかた・選挙権・選挙運動のきまり・議会のしくみと、比例代表の議席の配り方（ドント式）を確かめる1日5問の学習ゲームです。正解すると、もとになった法律の条文や総務省の説明が出ます。

遊ぶ: <https://satou-aaaaa.github.io/senkyo-shikumi/>

## 遊び方

- 今日の5問（だれでも同じ・1日1回）：しくみの問題4問と、議席の計算1問（党の得票から、ドント式で議席を配る）。
- 上級（むずかしいしくみ2問と、党と議席の多い計算1問・ヒントなし）・練習（分類ごと・何度でも）・とことん（まちがえても続き、「ここで降りる」まで）・おさらい（まちがえた問題）
- しくみ帳（55のしくみと出典）・実績・カレンダー（取りこぼした過去7日をあとから）
- 時間制限なし。記録は遊ぶ人のブラウザ（localStorage）だけに置き、外へ送りません。

## 中身の出どころ

公職選挙法・日本国憲法・地方自治法・最高裁判所裁判官国民審査法の条文（e-Gov 法令検索、2026年11月の版）と、総務省「選挙・政治資金」のページから作りました（一覧は `data.js` の `SRC` と、ゲームの「このゲームについて」）。問題を出す人物は作り話です。

- 計算の問題の「A党」などは記号で、本物の政党ではありません。特定の政党・候補者を応援したり、評価したりしません。
- 実際の選挙の投票日・投票所・時間は、住んでいる市区町村の選挙管理委員会のお知らせで確かめてください。
